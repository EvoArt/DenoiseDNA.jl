DenoiseDNA.DenoiseDNA — Module
DenoiseDNA

The DADA2 amplicon denoising pipeline: filterAndTrim, learnErrors, dada, mergePairs, makeSequenceTable and removeBimeraDenovo, with the names, options and results of the R package dada2.

DenoiseDNA.removePrimers — Function
removePrimers(fn, fout, primer_fwd, primer_rev=nothing; max_mismatch=2,
              allow_indels=false, trim_fwd=true, trim_rev=true, orient=true,
              compress=true, verbose=false) -> DataFrame

Keep only reads that contain the forward primer (and, if given, the reverse primer, in read orientation: e.g. rc(R1492)), trim the primers off and write the reads to fout. With orient, reads in which only the reverse complement holds the forward primer are turned around. IUPAC codes in a primer match any base they stand for. Port of R's removePrimers (used for PacBio full-length amplicons). Returns reads in and out per file.

DenoiseDNA.Derep — Type
Derep

Dereplicated reads of one sample.

  • sequence: unique sequences, most abundant first (ties keep lexical order).
  • abundance: number of reads of each unique.
  • quals: nunique x maxlen matrix of mean Phred quality per position (NaN past the end of a sequence).
  • map: for each input read, the index of its unique.

Error models

DenoiseDNA.learnErrors — Function
learnErrors(files_or_dereps; nbases=1e8, errorEstimationFunction=loessErrfun,
            multithread=false, randomize=false, MAX_CONSIST=10, OMEGA_C=0,
            verbose=false, progress, OPTIONS...) -> ErrorModel

Learn the error model by alternating sample inference and error rate estimation until convergence, using samples until nbases bases have been read (port of R's learnErrors). The progress display shows one line per self-consistency round, with the change in the error rates since the last one.

Sample inference

DenoiseDNA.dada — Function
dada(derep, err; selfConsist=false, pool=false, priors=String[], multithread=false,
     errorEstimationFunction=loessErrfun, verbose=false, progress, OPTION=value...)

Infer the exact sequence variants in each sample (port of R's dada).

  • derep: a Derep, a vector of them, or FASTQ file path(s).
  • err: 16-row error matrix (e.g. from learnErrors), or nothing with selfConsist=true.
  • pool: false (independent), true (pool all samples) or :pseudo.
  • priors: sequences with prior evidence of existence.
  • Options (OMEGA_A, BAND_SIZE, ...) are given as keywords; see DadaOptions.

Returns a DadaResult (or a vector of them for multiple samples).

progress=false hides the progress bar (default: DenoiseDNA.setprogress!).

With several rounds (selfConsist, or pool=:pseudo) alignments are reused between rounds; cache_alignments=false recomputes them (same results, slower).

source
DenoiseDNA.DadaResult — Type
DadaResult

Output of dada for one sample.

  • sequence, abundance: the denoised sequences (ASVs) and their read counts.
  • clustering: per-cluster diagnostics (as R's $clustering).
  • map: for each input unique, the index of its denoised sequence (0 = not corrected).
  • pval: final abundance p-value of each input unique within its cluster.
  • trans: observed transition counts by quality (16 x nq).
  • quality: mean quality of each denoised sequence (nclust x maxlen).
  • birth_subs: substitutions that drove the birth of each cluster.
  • err_in, err_out: error model(s) used and estimated.

DenoiseDNA.getBadBases — Function
getBadBases(clust, birth_subs; omegaB=1e-20, minOccurence=4, verbose=false) -> Vector{Int}

Positions where the one-off clusters of a dada result (clust = r.clustering, birth_subs = r.birth_subs) were born from more substitutions than chance allows: a Poisson upper tail, Bonferroni-corrected over positions, below omegaB, and at least minOccurence substitutions. source
DenoiseDNA.mergeSequenceTables — Function
mergeSequenceTables(tables...; repeats="error", orderBy="abundance", tryRC=false) -> SequenceTable

Combine sequence tables (for example from different sequencing runs) into one. Sample names repeated across tables are an error unless repeats is something else (e.g. "sum"), in which case their counts are summed. With tryRC, a sequence whose reverse complement appeared earlier is turned around and merged with it. Columns are ordered by orderBy ("abundance", "nsamples" or nothing).

Plots

The plotting functions need a Makie backend, e.g. using CairoMakie. qualityProfile and errorProfile return the plotted data and need no backend.

DenoiseDNA.plotQualityProfile — Function
plotQualityProfile(files; n=500_000, aggregate=false) -> Figure

Heatmap of quality scores by cycle for each FASTQ file, with the mean (green), median and quartiles (orange) and, for variable-length reads, the fraction of reads reaching each cycle (red). Requires a Makie backend (using CairoMakie).

source
DenoiseDNA.plotErrors — Function
plotErrors(x; nti="ACGT", ntj="ACGT", obs=true, err_out=true, err_in=false, nominalQ=false) -> Figure

Observed (points) and fitted (black line) error rates for each transition as a function of quality score; nominalQ=true adds the rates implied by the quality scores (red). Requires a Makie backend (using CairoMakie).

source
DenoiseDNA.plotComplexity — Function
plotComplexity(files; kmerSize=2, window=nothing, by=5, n=100_000, bins=100, aggregate=false) -> Figure

Histogram of sequence complexity (see seqComplexity) of the reads in each file. Requires a Makie backend (using CairoMakie).

source
DenoiseDNA.qualityProfile — Function
qualityProfile(file; n=500_000) -> NamedTuple

Per-cycle quality summary of (the first n reads of) a FASTQ file, as shown by plotQualityProfile: counts[cycle, q+1] reads with quality q at each cycle, and per-cycle mean, quartiles q25/q50/q75, and cum, the fraction of reads at least that long.

source
DenoiseDNA.errorProfile — Function
errorProfile(x) -> DataFrame

Long table of error rates by transition and quality, as shown by plotErrors: observed frequencies (count / tot), the fitted (Estimated) and input (Input) error rates and the Nominal rate implied by the quality score. x is an ErrorModel, a DadaResult (or vector of them) or an error matrix.
